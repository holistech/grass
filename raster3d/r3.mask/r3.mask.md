## DESCRIPTION

*r3.mask* facilitates the creation of a raster3d "MASK" map to control
raster3d operations. The raster3d *map* is used as the reference map.
Cells in the mask are marked as "mask out" if the corresponding cell in
*map* contains a value in the range specified with *maskvalues*.

## NOTES

Before a new 3D-mask can be created the existing mask has to be removed
with *g.remove*.

*r3.mask* writes the mask on the grid of *map*. A tool that applies the
mask hides a value where the mask is NULL at the location of that value:
at the centre of the cell of the current region for the tools that read
the map in the current region, such as *r3.out.ascii*, *r3.to.rast*,
*r3.univar* and *r3.mapcalc*, and at the location of the cell of the
cross section for *r3.cross.rast*. This holds in any current region and
for a map on any grid. For a map on the grid of the mask, the cells of
the map where the mask is NULL are hidden. With a mask on a finer or a
shifted grid, two cells of the current region that lie in the same cell
of the map can differ: one is hidden, the other shows the value of the
map.
