DESCRIPTION

The t.vect.list module provides the same functionality as t.rast.list, the only difference is the vector map layer metadata.

The methods delta, deltagaps and gran offer the columns interval_length and distance_from_begin; without columns they list id, name, layer, mapset, start_time, end_time, interval_length and distance_from_begin. The other methods do not offer these two columns. The delta methods support only the columns listed above, and the option order is not available with them, the rows are always ordered by start_time. The method comma prints the map ids in one line separated by commas, like the line format. The line format without columns lists the map ids. The method gran refuses an empty space time dataset.

EXAMPLE

Default query

This example show a relative space time vector dataset with the first three maps with a range of years, instead the last five are valid only for one year:

Using method option

Method option is able to show vector in different way. By default cols value is used, the value deltagaps will print the delta between maps and also the gaps if they exist (like in this example).
