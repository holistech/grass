DESCRIPTION

The purpose of t.vect.extract is to extract a subset of a space time vector dataset and to store that subset in a different space time vector dataset.

NOTES

With the suffix gran or time, maps registered for the same time get the same name. When their layers differ, for example two layers of one vector map, the layer is appended to the names, for example new_shoreline_2003_1 and new_shoreline_2003_2. Maps whose names are still equal, such as two different maps of January 2001 with layer 1, are numbered: the first of them, in the order of start time and map id, keeps the name; the second and every further map get the number _2, _3 and so on after it. A number that another new map has as its name is skipped.

EXAMPLE

In the following example a new space time vector dataset will be create with all the data later than the year 2000: 
t.vect.extract input=shoreline where="start_time > 2000" \
               output=shoreline_later_2000 basename=new_shoreline
