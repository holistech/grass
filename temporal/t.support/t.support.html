DESCRIPTION

The t.support module is dedicated to modify and update the metadata of a space time dataset.

The title, description and the semantic type can be modified. A call without the option semantictype leaves the semantic type as it is. The aggregation type of a space time raster dataset can be set with aggr_type, which takes any text and does not check it against the known aggregation methods; a space time vector dataset has none, so t.support warns about aggr_type for it and applies the other options. A call without -u, -m and any option changes nothing; it no longer updates the dataset as the former default of semantictype did.

The flag -u allows updating the STDS metadata from registered map layers. It computes the values from the entries of the registered maps in the temporal database and does not read the maps themselves. A map layer that was modified without using temporal commands is therefore not seen by -u; use -m for it.

The flag -m will update the metadata from registered maps, but also checks if the registered map layers have been removed from the spatial database. It deletes missing map layers from the space time dataset register table and the temporal database. Since 18.10.2026 the other space time datasets that hold a map layer read by -m are updated too, not only those that held a removed map layer.

EXAMPLES

Modification of title and description of space time raster dataset A. 

t.support type=strds input=tempmean_monthly title="Monthly temperature for North Carolina" \
          description="Dataset with monthly temperature for North Carolina"

Update the metadata of space time raster dataset A and check for removed map layers. 

t.support -m type=strds input=tempmean_monthly
